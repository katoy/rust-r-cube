## 3. テスト構造と内容の見直し成果

### (1) デッドコードの特定と数学的・論理的整理
- `src/thistlethwaite.rs`:
  - `bad_s.div_ceil(4) > depth` は `bad_s <= 4` かつ `depth >= 1` のため数学的に絶対に成立しないデッド枝刈りだったことを特定・除去。
- `src/search.rs`:
  - `phase2` の `depth == 0` 時、プルーニング距離が 0 である時点で数学的に `cp == 0 && ep == 0 && sp == 0` かつ全センター向き 0 が保証されているため、冗長な二重チェックを削除・健全化。
- `src/lib.rs`:
  - `result` ヘルパーにパース済み `cube` を直接渡す設計にリファクタリングし、冗長な再パースや二重エラーパスを排除。

### (2) タイムアウト・エラー伝播パスの精密検証
- `src/cfop.rs`:
  - `SolverState::check_timeout()` の 512 ノード周期判定に合わせ、`nodes = 510` を用いた確定的な再帰先タイムアウトテストを実装し、エッジケースのエラー伝播パスを完全網羅。
- `src/search.rs`, `src/korf.rs`:
  - 探索途中の時間切れによるフォールバック・None 返却パスを単体テストで確実に励起。

### (3) Web / E2E テストの拡充
- `tests/coverage.spec.ts` において、単体テスト（evaluate 内）と E2E 操作（UI / CDP）の統合スイートを整備。
- URL パラメータ復元、ファイルドラッグ＆ドロップ、各種解法（Kociemba / CFOP / Thistlethwaite / Korf）の切り替え、CFOP フェーズバッジ描画、キーボードショートカット、Service Worker キャッシュ整合性など、ブラウザ環境の全機能を包括的に検証。
