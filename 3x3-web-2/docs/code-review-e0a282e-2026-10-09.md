#### M8【Medium・確認済み（ネイティブ）／WASM 上の時間は推定】向き OFF の最短探索が 11 手の局面でタイムアウトしうる
- **箇所**:
  - `src/c2x2/search.rs:45-66`（24 通りの向きのループ）

- **原因**: `include_orientation=false` では、24 通りの向きそれぞれで IDA* を最初からやり直します。最初の解が 11 手だった場合、残りの 23 向きで深さ 10 までの探索を空振りします。さらに、2x2 の探索には時間制限がありません。
- **実測**（ネイティブ release）:
  - 11 手アンチポードで 5.0〜9.7 秒かかりました（例: `UUDBDLFUFRLLBDDFBRLUFRRB` で 9.7 秒）。

- **修正案**:
  - 向き OFF のときは、DBL コーナーが DBL 位置に向き 0 で収まる向きを 1 つだけ選び、IDA* を 1 回だけ回します。2x2 では、向きを問わない最短手数は DBL を固定したときの最短手数と同じです。
  - 予算から node の上限を決めます。
  - 11 手アンチポードの回帰テストを追加します。
